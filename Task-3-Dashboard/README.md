# Task 3 – Personal Finance Insights Dashboard

## Project Overview
I created an interactive dashboard using Microsoft Power BI to analyze a personal finance dataset containing 15,000 transaction records.

## Key Features
- KPI cards for total transactions, expenses, income, missing dates, missing amounts, and median amount.
- Charts for transaction categories, income vs. expenses, payment methods, and locations.
- A table showing the top 5 expense categories.
- A dark burgundy and red dashboard theme.
- Data quality findings to highlight missing values and unusual amounts.

## Tools Used
- Microsoft Power BI
- Power Query
- Data Visualization

## Key Findings
- Total records: 15,000
- Expense transactions: 12,760
- Income transactions: 2,240
- Missing dates: 9,256
- Missing amounts: 562
- Median transaction amount: 5,934
